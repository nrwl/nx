# Nx: Smart Monorepos · Fast Builds

Get to green PRs in half the time. Nx optimizes your builds, scales your CI, and fixes failed PRs. Built for developers and AI agents.

> `@nx/remix` is deprecated and will be removed in Nx 25. Nx 24 removes all executors and generators except `convert-to-inferred`.

Existing Remix v2 applications can keep using `@nx/remix/plugin` until Nx 25. The Nx 24 migration converts legacy executor targets to inferred tasks. Run `nx g @nx/remix:convert-to-inferred` to convert them manually.

For continued development, migrate to React Router with `@nx/react`. The `migrate-to-react-router` prompt migration guides an AI agent through the framework upgrade and Nx configuration, then asks it to run build and other relevant targets.

See the [Remix migration instructions](https://nx.dev/docs/technologies/react/remix/introduction).
